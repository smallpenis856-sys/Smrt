# Agent rules for this repo

**Ponytail is ON by default in this repo** (level: full), from
https://github.com/DietrichGebert/ponytail v5.3.3 (MIT — see
`.agents/skills/ponytail/LICENSE`).

Read and follow `.agents/skills/ponytail/SKILL.md` for every coding task:
the smallest complete change, no features/options/flexibility nobody asked
for, reuse what already exists before writing anything new, and end replies
with what was skipped and any risk the user must know.

Turn it off only if the user says "stop ponytail" or "normal mode"; switch
level with `/ponytail lite|full|ultra`.
