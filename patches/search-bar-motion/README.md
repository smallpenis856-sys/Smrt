# Subtle search-bar reveal — 660305

Replaces the exaggerated 660304 close-to-16%-then-reopen squeeze with a brief, one-way horizontal reveal of the active bar's decorative glass, 92% to 100% over 240 ms with a cubic ease-out. It is an iOS/Samsung-inspired approximation, not a reproduction of either OS's transition. Text, icons, editor, results, and menu are not scaled, translated, faded or otherwise animated by this helper. Existing navigation, no-home-flash behavior, IME timing and keyboard docking remain untouched. The animation is on search entry, not every tap while typing; it has no ongoing redraw loop and follows Android's animator duration setting.

Based on 660304, using the existing `SLSearchAnimation` entry/exit/detach hooks. On the next pre-draw the helper validates that the first direct child is the decorative glass widget and that search is visible and laid out; if not, it skips the effect. Cancellation, exit or detachment restores the original scale. It uses no custom pivot, and preserves the widget's existing translation and all foreground properties.

Rebuild: decode `SmartLauncher-SearchAnimation-660304.apk`, run `python3 patches/search-bar-motion/prepare.py <decoded>`, build with apktool, and replace `classes6.dex` using `python3 patches/search-bar-motion/replace_dex.py <built> <unsigned> patches/search-bar-motion/classes6.dex`. Align with `patches/all-apps-search/align_apk.py`, then sign. The helper dex was built using Android API 31, Java 8 and dx min SDK 24; disassembled smali is included. Run `python3 patches/search-bar-motion/check_build.py <decoded-660304> <decoded-output> <signed-apk>` and `SLSearchAnimationTest` with the supplied test stubs. The checker verifies unchanged launcher smali, GIFs, menus, resources and expected backdrop location. Automated tests, signing and alignment pass.

Signed with the 660304 key, so it should update 660304 without uninstalling. This key differs from 660303 and earlier builds, which cannot be updated in place. Backup/restore is unverified; uninstall can erase launcher data. No Android phone/emulator was available: the appearance, timing, keyboard, accessibility and in-place installation were not tested on a device, and a pixel-identical iOS/Samsung effect is not claimed.
