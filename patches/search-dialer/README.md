# Search number-keyboard button — build 660299

Based on 660298 and the user's screenshots. The active search bar's existing clear-button position now has a dialpad icon, visible even for an empty query. Tap switches the existing search editor to Android's phone input type and requests the current IME; tap again switches back to text input. Keyboard appearance and plus-key placement are determined by the user's keyboard app. Exiting search or detaching resets the editor to its original input type. Existing nonnumeric query text is selected when switching into number mode so typing replaces it without deleting it immediately; a numeric query is not selected automatically.

To preserve search clearing without another visual control, touch and hold the icon: this invokes the launcher's original clear-button handler, including its original navigation behavior. The button provides mode and long-press accessibility descriptions. The microphone, search glass, existing keyboard-dock and search actions are unchanged. The existing WhatsApp Business dialer card remains responsible for valid numeric results and the actual chat action; it requires the existing Mod Settings > WhatsApp Business Dialer toggle (on by default), a sufficiently long valid number, and an installed WhatsApp app. It uses the existing default country-code handling and Business-first fallback; it neither checks whether the number is registered nor reads messages. No new permission is added.
