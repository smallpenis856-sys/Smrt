# Home dock search pill — 660308

Based on 660307. Adds a small centered search pill only to the main home panel (panel ID 10), above the dock and above the visible page indicator when present. It uses a translucent rounded dark capsule, thin light outline, magnifier and localized Search label; the pill is an approximation of the reference, not a pixel-identical iOS component or live wallpaper blur. A 48dp minimum-height touch target opens the existing launcher search via `HomeScreen.H()` with no newly added search animation. Existing home search widgets, page indicators, dock, All Apps search and other launcher features are not replaced.

The pill anchors using the existing dock/indicator layout positions and updates on layout changes, not on every frame. It hides when the dock is hidden, when the launcher edit overlay is active, or when no safe measured position is available. The search pill does not reserve a new row in the home grid; with a densely populated/custom layout it may overlap widgets or icons and needs device testing. Existing indicator interaction is preserved by positioning the new touch target above it. Actual placement can vary with themes, orientation, large fonts and dock configuration.

Rebuild: decode `SmartLauncher-UndoSearchDrawer-660307.apk`, run `python3 patches/home-search-pill/apply.py <decoded>`, build with apktool, append the included helper dex using `python3 patches/search-bar-animation/append_dex.py <built> <unsigned> patches/home-search-pill/classes6.dex`, align with `patches/all-apps-search/align_apk.py`, then sign. Java 8/API31/dx min SDK 24 compile inputs are `SLHomeSearch.java` and `SLPillPosition.java`; the HomeScreen stub is compile-only and excluded. Disassembled helper smali is included.

`SLPillPositionTest` covers dock/indicator anchors and invalid/small layouts. `python3 patches/home-search-pill/check_build.py <decoded-660307> <decoded-output> <signed-apk>` verifies home-only hook, unchanged original launcher methods beyond two scoped hooks, preserved no-animation search and drawer behavior, resources, GIFs and signing helper. GIF, backup, dialer and task host tests, APK alignment and v2/v3 verification passed. The certificate matches 660304–660307, so it should update those builds; it cannot update 660303 or earlier in place.

No Android device/emulator was available. Pixel appearance, overlap, whether the dock pager/indicator anchors are appropriate on the user's configuration, edit mode, accessibility, interaction and update install are not device-tested.
