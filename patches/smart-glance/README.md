# Smart Glance Island — build 660289

Based on the signed 660288 `SmartLauncher-AllAppsSearch-NoFlash.apk`. Adds `SLGlanceIsland` as the last child of `homeContent` in `home_panel.xml`; it is not an Android AppWidget, so the top/bottom fixed placement can overlap existing home widgets. Long-press the capsule to change placement and sources. Tap it to expand the information panel.

The compact label prioritizes low battery (20% or lower), active music, a calendar event due within an hour, then the first incomplete task dated today in the existing `sl_agenda_panel_v1` store. Expanded panel shows each enabled source and a play/pause action when the active or paused media session advertises a corresponding transport action. Battery and today's tasks are on by default; music and calendar are off until enabled. Calendar permission and notification-listener access are optional and requested/opened only via settings. This is an original translucent dark capsule, not the existing live/native glass widget or the iOS implementation.

Events use the platform battery/time broadcasts, the existing agenda SharedPreferences listener, calendar ContentObserver and MediaSession callbacks. Calendar provider queries run off the UI thread on home visibility, time/date changes, calendar changes and expiration of the current event; time ticks update the cached event's one-hour display threshold, not a repeating provider query. There is no GPS, network fetch or self-scheduled polling loop. The view subscribes only while its home position is visible and its window is visible; detach/window hidden unregister receivers, observers and media callbacks. Existing background reminders and weather are untouched. Accessibility text is supplied, though colors, sizing, clipping, underlying widget overlap, gestures and screen readers require device testing.

Calendar displays the next timed event from the next 24 hours (all-day events omitted). Tasks are today's incomplete agenda tasks, not time-accurate reminder alerts. Music requires the launcher's existing notification listener to be enabled and a compatible media session; the system may expose only limited actions. This does not read arbitrary notifications or message content. Details do not automatically open the agenda. Toggling sources and positioning are stored locally and do not affect existing launcher settings.
