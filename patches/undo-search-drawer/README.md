# Undo added search animation and drawer fade change — 660307

Restores the exact launcher code and resources from `SmartLauncher-RestoreMenus-660303.apk`, before builds 660304–660306 added search-bar animations and altered the All Apps grid's top fade. There is no added search-bar transition or delayed drawer click. All Apps reverts to its earlier behavior, including the original top fade. Existing pre-660304 native workspace/panel transitions, GIF settings, menus, search behavior and other features remain as they were in 660303.

Rebuild: `python3 patches/undo-search-drawer/prepare.py SmartLauncher-RestoreMenus-660303.apk <unsigned>` changes the unique binary manifest `versionCode` integer from 660303 to 660307 and removes old JAR signatures. Then align with `patches/all-apps-search/align_apk.py` and sign with the 660304–660306 key. Run `python3 patches/undo-search-drawer/check_build.py <660303-apk> <signed-apk> <decoded-signed-apk>`: it compares every ZIP entry except signature files and the four version-code bytes, verifies the new version after decoding, and checks the removed animation hooks and restored original grid and no-flash drawer search path. Alignment, v2/v3 signatures, and GIF, backup, dialer and task host tests passed.

The signing certificate matches 660304–660306, so this build should update those versions without uninstalling. It is not signed with the 660303 key and cannot update 660303 or earlier in place. No phone/emulator was available: update installation, actual search navigation and restored drawer appearance have not been device-tested. Do not rely on backup/restore without testing it.
